# HA Gaming Hub

A HACS custom integration for Home Assistant that brings gaming data into your smart home.

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/integration)

## Installation

> Installation instructions will be added once the integration reaches a stable release.

## Modules

- **Free Games** — tracks free game promotions from Epic Games Store and other platforms
- **Price Tracker** — monitors game prices and alerts on deals via CheapShark / IsThereAnyDeal
- **Presence** — shows Steam and Xbox online status for tracked accounts
